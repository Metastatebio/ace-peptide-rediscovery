# Bioinformatics Advances Submission Checklist

Checked: 2026-09-18

Sources:

- https://academic.oup.com/bioinformaticsadvances/pages/about
- https://academic.oup.com/bioinformaticsadvances/pages/author-guidelines

## Format

- Article type: Original Article.
- Journal fit: bioinformatics/computational biology; sequence analysis; machine learning and AI; proteomics/metabolomics; cheminformatics.
- Title: ProteinLM-specific, no therapeutic overclaim.
- Abstract: prepared in single-paragraph form.
- Keywords: prepared.
- Main sections: Introduction, Results, Discussion, Methods, Data availability, Funding, Competing interests, Author contributions, Acknowledgements, References.
- AI-assisted tool use: documented in Methods.

## Required Files

- Manuscript text: `submission/bioinformatics-advances/manuscript.md`
- Cover letter: `submission/bioinformatics-advances/cover-letter.md`
- Metadata: `submission/bioinformatics-advances/metadata.md`
- Supplementary information: `submission/supplementary-information.md`
- Reproducibility manifest: `submission/reproducibility-manifest.md`
- Runtime pins for PLM scenarios: `submission/protein-lm-runtime-requirements.txt`
- Main figures: `figures/submission/*.svg`; convert to TIFF/PNG/PDF only if the submission system requires it.

## Remaining Before Upload

- Obtain the sole author's signed attestation of authorship, declarations, and submission approval.
- Public `v0.1.0` repository tag verified; an archival DOI is optional.
- Convert figures if the upload form rejects SVG.
- Add suggested and excluded reviewers if requested by the submission system.
